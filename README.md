C++ Programming Concepts
Description

This repository contains a collection of C++ programs demonstrating fundamental object-oriented programming concepts, functions, and basic calculations. These programs are created for learning and practicing C++ programming.

Programs Included
1. Student Details Using Class and Object

A program that accepts and displays a student's roll number and name using a class and object.

Concepts Used:

Classes and Objects
Data Members and Member Functions
User Input and Output
2. Student Details Using Inheritance

A program demonstrating single inheritance using two classes to store and display a student's roll number, name, and marks.

Concepts Used:

Single Inheritance
Public, Private, and Protected Access Specifiers
Classes and Objects
3. Static Data Member — Object Counter

A program that uses a static data member and a constructor to count the total number of Student objects created.

Concepts Used:

Static Data Members
Constructors
Classes and Objects
4. Pass by Value and Pass by Reference

A program demonstrating the difference between passing variables by value and by reference, along with passing an object to a function.

Concepts Used:

Functions
Pass by Value
Pass by Reference
Passing Objects to Functions
5. Factorial Using an Inline Function

A program that calculates the factorial of a number entered by the user using an inline function and a for loop.

Concepts Used:

Inline Functions
For Loop
Return Values
6. Area of Rectangle Using a Class

A program that calculates the area of a rectangle using private data members and member functions defined outside the class.

Formula:

Area = Length × Breadth

Concepts Used:

Classes and Objects
Private Data Members
Scope Resolution Operator (::)
Member Functions Defined Outside the Class
Technologies Used
Programming Language: C++
Concepts: Object-Oriented Programming (OOP) and Basic Programming
